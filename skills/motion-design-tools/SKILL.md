# Motion & Design Tools (curated)

A decision map for picking the right motion/design tool per case, plus inspiration sources.

## Pick by need
- **3D animations / scenes** → spline.design (no-code 3D, exports to web/React).
- **WebGL / shaders / effects** → unicorn.studio (shader presets, ships to web).
- **2D vector animation (Lottie)** → lottiefiles.com (huge library + editor).
- **Advanced prototyping / logic** → protopie.io (interactive, conditional logic).
- **Micro-interactions / UI motion** → lottielab.com (small, product-grade Lottie).
- **App UI inspiration** → 60fps.design (real app interactions).
- **Web inspiration / awards** → awwwards.com (site of the day, patterns).
- **In-code animation** → framer-motion / Motion (already in this project), springs, layout animations.
- **Icon morphing** → `morphicons` skill.
- **3D components** → `threejs-ui` skill (threeui.com).
- **React copy-paste effects** → `react-bits` skill.

## How to advise
1. Match the tool to the medium: DOM/CSS vs canvas/WebGL vs video/Lottie.
2. Prefer the cheapest tool that hits the goal (CSS > JS > WebGL > video).
3. Always define the motion's purpose and duration/curve (see `emil-design-eng`).
4. Provide a reduced-motion fallback.
