# Refining AI-generated UI (keep the good, fix the generic)

Goal: raise an AI-built interface to a deliberate, high-craft level while PRESERVING what already works. This is a surgical pass, not a rewrite.

## Core principle
**Read first, change with intent.** Inventory the existing UI before touching it. The failure mode of AI polish is throwing away working structure, spacing, or a good idea and replacing it with a different generic look. Keep the skeleton and the nice details; fix only what reads as default/templated.

## Workflow
1. **Audit (read, don't write).** List every screen/component, its states (empty, loading, error, long content, mobile), and the design tokens in use (`tailwind.config.ts`, CSS variables, HeroUI theme). Note what already looks good — mark it "keep".
2. **Diagnose the "slop tells":**
   - Default font (Inter/system) with no pairing; flat gray text on colored bg; pure black/white; low-contrast text.
   - Cards nested in cards; everything same radius/shadow; equal emphasis everywhere (no hierarchy).
   - Bouncy/elastic easing on serious actions; animations on keyboard-driven or frequent actions; no reduced-motion.
   - Magic-number spacing (13px, 27px) instead of a scale; inconsistent gaps.
   - Placeholder copy, generic hero, stock icon soup.
3. **Fix in priority order (impact × effort):**
   - Hierarchy: size/weight/color/spacing to establish one clear primary action per screen.
   - Type scale + pairing; tighten line-height; fix tabular numbers where relevant.
   - Spacing on an 4/8px scale; consistent radii and a single elevation story.
   - Color: one accent, semantic success/warn/error, sufficient contrast (WCAG AA).
   - Motion: purpose, correct curve/duration, reduced-motion fallback.
   - States: empty, loading (see `loading-dev`), error, disabled, focus-visible.
4. **Preserve the wins.** Explicitly keep the parts marked "keep". Only replace a detail if the replacement is objectively better, and say why.
5. **Verify.** Run typecheck/lint; check responsive + dark mode; ensure no regressions in behavior.
